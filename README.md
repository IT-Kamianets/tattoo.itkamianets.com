3D-ПРИМІРОЧНА ТАТУ — ФАЙЛИ ДЛЯ GITHUB

1. Розпакуй цей архів.
2. Відкрий репозиторій IT-Kamianets/tattoo.itkamianets.com.
3. Add file → Upload files.
4. Перетягни всі файли й папки зсередини розпакованої папки.
   index.html, CNAME і папка models мають лежати в корені репозиторію.
5. Commit changes.
6. Settings → Pages → Deploy from a branch.
   Обери гілку з цими файлами та папку / (root), натисни Save.
   У Custom domain має бути tattoo.itkamianets.com.

У комплекті вже є обидві GLB-моделі, Three.js, ескізи та інші ресурси.
Моделі мають приблизно 19 МБ кожна, тому перше завантаження може тривати.
Примірочна працює після публікації через GitHub Pages або через локальний вебсервер.

ЯК ПРИМІРЯТИ
Вибери модель, завантаж PNG/JPG/WebP або вибери зразок.
Натисни «Розмістити тату», потім натисни на тіло.
Налаштуй розмір, поворот та насиченість.
«Завершити розміщення» повертає обертання моделі.
Колесо миші або жест двома пальцями змінює масштаб.
«Наблизити тату» фокусує камеру на ескізі.
Після зміни моделі вибери місце для тату заново.
Кожна модель використовується у нерухомій позі.
